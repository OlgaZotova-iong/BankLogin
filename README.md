# Advanced QA: Integration Testing with MySQL & Docker

Комплексный проект по автоматизации тестирования банковского веб-приложения с интеграцией базы данных и контейнеризацией.

## Описание проекта
Проект демонстрирует навыки построения полноценного тестового окружения. Основная задача — проверка бизнес-логики приложения, работающего с СУБД MySQL, через UI-интерфейс, с учетом требований безопасности и работы с данными.

## Стек технологий
- **Язык:** Java 11
- **Тестовый фреймворк:** JUnit 5
- **UI-тестирование:** Selenide
- **База данных:** MySQL 8, Apache DBUtils
- **Генерация данных:** JavaFaker
- **Инфраструктура:** Docker, Docker-compose
- **Паттерны:** Page Object, Data Helper

## Ключевые реализованные задачи
1. **Контейнеризация:** Настройка `docker-compose.yml` для поднятия изолированного тестового окружения (приложение + база данных).
2. **Работа с СУБД:**
    - Реализация утилитного класса для взаимодействия с БД (`SQLHelper`).
    - Получение верификационных кодов напрямую из базы данных для автоматизации сценария входа.
    - Очистка базы данных после каждого теста (`cleanDatabase`, `cleanAuthCodes`) для обеспечения изолированности тестов.
3. **Бизнес-логика:**
    - Автоматизация сценария успешной авторизации с использованием данных из БД.
    - Проверка негативных сценариев (неверный логин/пароль, неверный код верификации).
4. **Архитектура:**
    - Применение паттерна **Page Object** для инкапсуляции логики взаимодействия с элементами страниц.
    - Использование **Data Helper** для генерации тестовых данных (включая случайные данные через JavaFaker).

## Как запустить
1. Убедитесь, что у вас установлен Docker.
2. Запустите контейнеры: `docker-compose up`
3. Запустите тесты: `./gradlew test`
